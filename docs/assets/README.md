## 项目标志

- [logo.svg](brand/logo.svg)：128 × 128 矢量标志，可无损缩放。
- [logo.png](brand/logo.png)：512 × 512 透明背景导出，适合演示文档。
- [banner.svg](brand/banner.svg) / [banner.png](brand/banner.png)：1200 × 360 项目首页横幅。

标志外框取自字母 **C** 与教室平面图，内部四块座位代表空间资源，薄荷绿节点代表连接与协作。主色为深靛蓝 `#101628`、浅靛蓝 `#A5B4FC` 与薄荷绿 `#5EEAD4`。

本次标志用于仓库文档，应用内图标保持现有样式。

## 页面截图

`screenshots/` 中的六张 PNG 均由本地运行的前端直接截取，未重绘界面或拼接业务数据。

- 运行方式：在 `ICMS-frontend/` 下执行 `npm run dev:e2e`。
- 数据来源：全新浏览器会话中的 Mock 演示数据，非线上业务数据。
- 登录角色：系统管理员 `admin`，账号说明见 [开发指南](../DEVELOPMENT.md#本地演示账号)。
- 截图尺寸：1600 × 1000，设备缩放比例为 1。
- 页面范围：浅色 / 深色仪表盘、教室资源、报修工单、环境监测、预约审批。

更新截图时，等待数据和图表加载完成，移开鼠标以避免提示浮层，并保留上述文件名。页面中的日期、统计及环境读数来自演示程序，不代表真实校园运行情况。
