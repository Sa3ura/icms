# ICMS 智慧教室管理系统页面白板原型

## 1. 原型说明

本文档采用 Markdown 白板线框方式描述 ICMS 系统主要页面结构，适用于前端 Vue 页面开发、需求评审和毕业设计文档展示。页面布局以后台管理系统为主，建议采用 Vue 3 + Vue Router + Pinia + Element Plus 实现。

## 2. 全局布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部导航栏：系统名称 | 当前用户 | 消息通知 | 修改密码 | 退出登录 │
├───────────────┬──────────────────────────────────────────────┤
│ 左侧菜单栏     │ 主内容区                                      │
│ - 首页仪表盘   │ 面包屑导航                                    │
│ - 教室管理     │ 查询区域                                      │
│ - 设备管理     │ 数据表格 / 表单 / 图表                         │
│ - 预约管理     │ 分页 / 操作按钮                                │
│ - 报修工单     │                                              │
│ - 系统管理     │                                              │
└───────────────┴──────────────────────────────────────────────┘
```

### 页面元素

| 元素 | 类型 | 说明 |
|---|---|---|
| 用户名 | 输入框 | 必填 |
| 密码 | 密码框 | 必填，隐藏显示 |
| 验证码 | 输入框 | 可选，连续失败后启用 |
| 登录按钮 | 按钮 | 调用登录接口 |
| 忘记密码 | 链接 | 跳转密码重置页面 |

## 4. 首页仪表盘

```text
┌──────────────────────────────────────────────────────────────┐
│ 首页 / 仪表盘                                                 │
├──────────────────────────────────────────────────────────────┤
│ [教室总数] [今日预约] [待审批] [待处理工单] [设备故障数]       │
├──────────────────────────────┬───────────────────────────────┤
│ 教室使用率折线图             │ 设备状态饼图                   │
├──────────────────────────────┴───────────────────────────────┤
│ 今日课程/预约列表                                             │
│ 教室 | 时间 | 课程/用途 | 使用人 | 状态                        │
└──────────────────────────────────────────────────────────────┘
```

### 主要交互

- 点击「待审批」跳转到预约审批列表。
- 点击「待处理工单」跳转到工单管理。
- 图表支持按校区、日期筛选。

## 12. 系统管理页面

### 12.1 用户管理

```text
查询条件：用户名、真实姓名、用户类型、状态
操作按钮：新增、编辑、禁用、重置密码、分配角色
表格字段：用户名、姓名、手机号、邮箱、用户类型、状态、创建时间
```

### 12.2 角色管理

```text
查询条件：角色编码、角色名称、状态
操作按钮：新增、编辑、删除、分配权限
表格字段：角色编码、角色名称、描述、状态、创建时间
```

### 12.3 菜单权限管理

```text
左侧：菜单树
右侧：菜单详情、按钮权限、接口权限
操作：新增菜单、新增按钮、编辑、删除、排序
```

### 12.4 操作日志

```text
查询条件：用户名、操作类型、请求方式、时间范围、结果状态
表格字段：用户、操作、请求URL、IP、结果、异常信息、时间
```
